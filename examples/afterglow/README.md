# Afterglow / 余温

A self-initiated chat-interface concept made by Codex for John Tan's portfolio. This is not a client project, a production companion service, or evidence of customer results.

## Preview

Open `index.html` in a browser, or serve this repository locally and open `/examples/afterglow/`.

Warm paper tones, original CSS landscape graphics, a quieter message hierarchy, desktop contextual controls, and a single-column mobile layout. Features include day/night mode, three accent palettes, reduced motion, topic prompts, local message entry, and reset.

**All replies are explicitly scripted.** No model, backend, authentication, payment, persistence, analytics, or message transmission is implemented. Reloading resets the conversation. Never enter sensitive information into a demonstration.

## Verification

Verified in Chrome: a topic fills the composer; sending appends the user's text and a labeled scripted reply; the empty composer disables sending; day/night theme switches. Desktop and 390px mobile layouts were visually inspected, with no horizontal document overflow in the mobile check. Enter-key sending, the green accent selector and reduced-motion switch were also checked against their rendered state.

This standalone HTML/CSS/JavaScript example is offered as a visual and interaction sample. Production integration, real model behavior, accessibility audit, cross-browser testing and client-specific design work would require a separate agreed scope.
